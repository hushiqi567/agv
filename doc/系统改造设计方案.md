# AGV路径规划系统改造设计方案

> 设计日期：2026-05-27 | 答辩日期：2026-06-16 | 主题：基于强化学习的AGV路径规划算法设计

---

## 一、改造目标

当前系统架构为 **CBS（传统搜索）主导全局规划 + DQN 辅助局部避撞**，与开题报告"基于强化学习的AGV路径规划"定位严重不符。

改造目标：**RL 成为路径规划的唯一核心**，CBS 降级为实验对照组。

---

## 三、RL算法方案：DQN渐进 → PPO备选

采用 **先 DQN 后 PPO** 的渐进策略：
1. 先用当前 DQN 框架快速跑通单AGV，验证环境正确性
2. 如果 DQN 效果不理想或时间允许，升级到 PPO

### 3.1 状态空间

从 5×5 扩大到 **15×15 局部网格（5通道）** + 全局特征向量：

| 通道 | 内容 | 说明 |
|------|------|------|
| 1 | 静态障碍物 | 货架、墙壁等不可通行区域 |
| 2 | 其他AGV位置 | 动态实体，实时更新 |
| 3 | 移动障碍物 | 随机移动的障碍物 |
| 4 | 目标方向热力图 | 指示目标位置方向 |
| 5 | 前方拥堵预警 | 新增，用于死锁预防 |

**全局特征向量**：到目标距离、当前电量、负载状态、任务优先级。

### 3.2 动作空间

保持5个离散动作：上、下、左、右、等待。

### 3.3 奖励函数设计

按任务流程分段设计：

**阶段1 — 导航奖励（AGV前往取货点/送货点）**：
| 奖励项 | 值 | 说明 |
|--------|-----|------|
| 接近目标 | +1.0 | 曼哈顿距离缩短 |
| 远离目标 | -1.0 | 曼哈顿距离增加 |
| 每步惩罚 | -0.1 | 鼓励最短路径 |
| 碰障碍物 | -10 | 物理碰撞惩罚 |
| 碰其他AGV | -20 | 多AGV碰撞惩罚 |
| 到达目标 | +100 | 到达取货点或送货点 |

**阶段2 — 装卸奖励**：
| 奖励项 | 值 | 说明 |
|--------|-----|------|
| 成功装货 | +20 | 在取货点装载货物 |
| 成功卸货 | +20 | 在送货点卸载货物 |
| 装卸超时 | -0.5/步 | 鼓励快装快卸 |

**阶段3 — 全局奖励**：
| 奖励项 | 值 | 说明 |
|--------|-----|------|
| 完整任务完成 | +200 | 取货→送货全流程 |
| 死锁/卡死 | -100 | 配合死锁检测 |
| 低电量 | -5/步 | 电量<20%触发 |

**多AGV额外奖励**：
| 奖励项 | 值 | 说明 |
|--------|-----|------|
| 通道共享 | +5 | 狭窄通道成功交错通过 |
| 拥堵惩罚 | -2/步 | 同一区域聚集≥3个AGV |

## 四、课程学习：分三阶段训练

| 阶段 | 地图 | 静态障碍物 | 移动障碍物 | 目标成功率 |
|------|------|-----------|-----------|-----------|
| 1 | 10×10 小地图 | 3-5个 | 无 | >80% |
| 2 | 30×30 中地图 | 5-8个 | 2-3个 | >80% |
| 3 | 50×50 完整地图 | 10个 | 全部 | 尽可能高 |

每个阶段使用自动生成的100个随机场景（起点、终点、障碍物随机化），确保模型学会通用导航能力。

## 五、多AGV MARL方案

采用**先独立训练后参数共享**的渐进策略：

### 阶段1：独立训练 + 参数共享
- 所有AGV使用同一个训练好的RL模型
- 训练时在多AGV场景中随机初始位置，让模型自然学会避让

### 阶段2（备选）：CTDE架构
- 如独立训练效果不佳，升级到集中训练分散执行
- Centralized Critic 在训练时观察全局信息
- Decentralized Actor 执行时只看局部
- 答辩时可包装为 MARL 协同机制

## 六、死锁检测与恢复

### 6.1 检测机制
每10步扫描一次，用**有向图判环**检测循环等待：
- 节点 = AGV
- 有向边 = AGV A 在等待 AGV B 让路
- 检测图中是否存在环

### 6.2 恢复策略
- 选参与死锁中"执行任务时间最短"的AGV
- 让它随机回退一步，打破循环
- 给予 -100 惩罚，让RL学会避免

### 6.3 预防
在RL状态中增加通道5"前方拥堵预警"，让RL预判并主动绕行。

## 七、核心指标采集（MetricsCollector）

新增独立模块，挂载在 MessageBus 上，自动记录：

- 每步每个AGV的位置和状态
- 任务完成时间
- 路径长度
- 碰撞次数
- 死锁触发次数和恢复耗时
- 训练过程的损失曲线、奖励曲线、探索率变化

自动导出 CSV 和 matplotlib 图表，直接用于技术报告。

## 八、实验设计

### 实验一：单AGV RL vs 传统A\*
- 同一地图、同样起点终点
- 指标：路径长度比值（越接近1越好）、到达成功率

### 实验二：消融实验
| 配置 | RL全局规划 | 局部避撞 | 课程学习 | 死锁检测 |
|------|:---:|:---:|:---:|:---:|
| 完整系统 | ✓ | ✓ | ✓ | ✓ |
| 去掉课程学习 | ✓ | ✓ | ✗ | ✓ |
| 去掉局部避撞 | ✓ | ✗ | ✓ | ✓ |
| 仅全局规划 | ✓ | ✗ | ✗ | ✗ |

### 实验三：多AGV可扩展性
从2台到8台AGV，观察：
- 任务完成率
- 平均每任务耗时
- 碰撞次数/千步
- 预期：吞吐量递增但边际递减

### 实验四：对比传统方法
- MARL vs 纯CBS vs 随机策略
- 三个维度：路径效率、碰撞率、死锁次数
- 如时间紧张，用4台AGV跑

共产生约6-8张图和对应表格，直接可用于答辩和技术报告。
